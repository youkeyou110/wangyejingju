## 快速开始

### 安装扩展

1. Chrome 网上应用店安装（推荐）
   - 访问 [Chrome 网上应用店]()
   - 点击"添加到 Chrome"

2. 手动安装
   - 下载最新版本的 zip 文件
   - 解压到本地文件夹
   - 打开 Chrome 扩展管理页面 (`chrome://extensions/`)
   - 开启"开发者模式"
   - 点击"加载已解压的扩展程序"
   - 选择解压后的文件夹

### 基本使用流程

1. 选择文本
   - 在网页中选中想要制作成卡片的文本
   - 右键点击，选择"生成金句卡片"
   - 或使用快捷键 `Ctrl+Shift+Q`

2. 编辑卡片
   - 选择喜欢的模板
   - 调整样式设置
   - 实时预览效果

3. 导出图片
   - 点击"导出图片"按钮
   - 选择导出格式和质量
   - 保存到本地

## 基本功能

### 文本选择

- **右键菜单选择**
  - 选中文本后右键
  - 点击"生成金句卡片"

- **快捷键选择**
  - Windows/Linux: `Ctrl+Shift+Q`
  - macOS: `Command+Shift+Q`

- **多段文本**
  - 支持选择多个段落
  - 自动保持段落格式

### 模板系统

- **预设模板**
  - 简约白：清新简洁的白色背景
  - 优雅灰：低调内敛的灰色调
  - 现代蓝：充满活力的蓝色主题
  - 复古棕：怀旧风格的暖色调
  - 暗夜黑：高端大气的深色主题

- **自定义模板**
  - 创建个性化模板
  - 保存常用样式
  - 导入/导出模板

### 样式编辑

- **背景设置**
  - 纯色背景
  - 渐变背景（线性/径向）
  - 自定义颜色

- **字体设置**
  - 字体选择
  - 字号大小
  - 字体颜色
  - 字体粗细
  - 行高调整
  - 字间距调整

- **布局设置**
  - 内边距
  - 对齐方式
  - 宽度调整
  - 高度调整

- **特效设置**
  - 阴影效果
  - 边框样式

### 导出功能

- **格式选择**
  - PNG（推荐）：无损质量，支持透明
  - JPEG：较小文件体积
  - WEBP：新一代图片格式

- **质量控制**
  - 调整压缩比例
  - 平衡质量和体积

- **尺寸调整**
  - 缩放比例
  - 保持清晰度

## 常见问题

### 为什么某些网站无法选择文本？

某些网站可能禁用了文本选择功能。这种情况下，您可以：
1. 尝试使用浏览器的阅读模式
2. 复制文本后直接粘贴到编辑器中

### 如何调整导出图片的清晰度？

1. 点击"导出图片"
2. 在导出设置中：
   - 选择 PNG 格式获得最佳质量
   - 增加缩放比例（如 2x）提高清晰度
   - 调整质量滑块（仅影响 JPEG/WEBP）

### 如何备份我的自定义模板？

1. 所有自定义模板都自动保存在浏览器中
2. 清除浏览器数据时请注意不要删除扩展数据
3. 建议定期导出重要的自定义模板

## 故障排除

### 扩展无法正常工作

1. 检查扩展是否启用
2. 刷新当前页面
3. 重启浏览器
4. 重新安装扩展

### 样式预览不更新

1. 检查是否有样式设置未正确应用
2. 尝试切换��板后再切回
3. 刷新扩展页面

### 导出失败

1. 检查是否有足够的磁盘空间
2. 确保导出路径可写
3. 尝试不同的导出格式
4. 减小图片尺寸后重试

### 存储空间不足

1. 删除不需要的自定义模板
2. 清理操作日志
3. 导出重要模板后重置扩展

如果问题仍然存在，请：
1. 查看控制台是否有错误信息
2. 提交 issue 并附上详细的问题描述
3. 包含浏览器版本和扩展版本信息
