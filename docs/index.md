# 金句卡片生成器

欢迎使用金句卡片生成器! 这是一个帮助用户生成精美金句卡片的Chrome扩展。

## 功能特点

- 一键生成精美卡片
- 多种模板选择
- 自定义样式设置
- 便捷的分享功能

## 快速开始

1. 从Chrome商店安装扩展
2. 选择网页文本
3. 右键点击"生成金句卡片"
4. 选择模板并编辑样式
5. 导出或分享卡片
